# 공개 보류 사진

여기 있는 사진은 **홈페이지에 올리지 않았습니다.**

현재 생존해 계시거나 최근 작고하신 분이 알아볼 수 있게 담겨 있어,
유가족의 공개 동의를 확인한 뒤에 올리는 것이 맞다고 판단했습니다.
사이트의 원칙("가족을 먼저 생각합니다")에 따른 것입니다.

- `veteran-visit-a.jpg` — 참전용사 어르신과 방문한 젊은 분들
- `veteran-visit-b.jpg` — 참전용사 어르신과 윤정화 선교사

동의가 확인되면 `public/gallery` 로 옮겨 갤러리에 싣겠습니다.
이 폴더는 공개되지 않는 위치이므로, 인터넷에서 열리지 않습니다.
