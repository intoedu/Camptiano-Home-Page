# 사진 넣는 곳

이 폴더에는 갤러리 페이지에 들어갈 사진을 올립니다.

## GitHub 웹에서 바로 올리는 방법

1. GitHub 저장소에서 이 폴더(`public/images`)를 엽니다
2. 오른쪽 위 **Add file → Upload files** 클릭
3. 사진을 끌어다 놓고 아래 **Commit changes** 클릭

파일 이름은 영문·숫자로 지어 주세요. (예: `chairman.jpg`, `memorial-01.jpg`)
한글 파일명은 주소에서 깨질 수 있습니다.

## 어떤 사진을 어디에 두나요

| 폴더 | 용도 |
| --- | --- |
| `public/images/` | 인물 사진, 히어로 이미지 등 페이지에 직접 쓰는 사진 |
| `public/gallery/` | 갤러리 페이지에 들어갈 사진 모음 |

올리신 뒤 알려 주시면 사이트의 알맞은 자리에 연결하겠습니다.
