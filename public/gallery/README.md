# 사진 올리는 곳

이 폴더에 사진을 올리면 홈페이지에 씁니다.

## 올리는 방법 (1분)

아래 주소를 누르면 **바로 이 폴더의 업로드 화면**이 열립니다.

**https://github.com/intoedu/Camptiano-Home-Page/upload/main/public/gallery**

1. 사진을 화면으로 **끌어다 놓습니다** (여러 장 한 번에 가능)
2. 아래로 내려 초록색 **Commit changes** 를 누릅니다

끝입니다. 파일 이름은 아무렇게나 두셔도 되고, 올리신 뒤 알려 주시면
어느 자리에 넣을지 정해서 연결하겠습니다.

## 부탁드릴 것

- **원본 크기 그대로** 올려 주세요. 카카오톡으로 주고받은 사진은 화질이
  줄어 있어, 크게 걸면 흐릿합니다.
- 오래된 사진은 **스캔이 가장 좋고**, 어려우면 밝은 곳에서 정면으로
  찍은 사진도 충분합니다.
- 유가족 사진은 **공개 동의를 받은 것만** 올려 주세요.
